💡 ¿Dónde obtener tus credenciales de Mercado Pago?
  1. Iniciá sesión en Mercado Pago Developers.
  2. Hacé clic en Tus Integraciones ➔ Seleccioná tu aplicación (o creá una nueva tipo Checkout Pro).
  3. En el menú lateral hacé clic en Credenciales de Prueba (para probar) o Credenciales de Producción.
  4. Copiá el Access Token que empieza con TEST- o APP_USR- y pegalo arriba.

💡 Guía para obtener tus credenciales de Google Custom Search (Gratis - 100 búsquedas/día)
  1. Ingresa a Google Cloud Console - Custom Search API y haz clic en Habilitar.
  2. En APIs y Servicios ➔ Credenciales, haz clic en Crear Credencial ➔ Clave de API. Copia la API Key obtenida.
  3. Ingresa a Google Programmable Search Engine y haz clic en Añadir:
    • Nombre: Kido Garage Imagenes
    • ¿Qué buscar?: Buscar en toda la Web
    • Activa la casilla Búsqueda de Imágenes y SafeSearch.
  4. En la pestaña Configuración básica del motor creado, copia el ID del motor de búsqueda (CX) y pégalo arriba.
  5. Nota: Si dejas los campos vacíos, el sistema utiliza el repositorio público de Wikimedia Commons / Creative Commons para seguir proveyendo fotos libres de derechos sin costo.
